Lab 1: Volleyball Basics

In this lab, we will learn the basics of volleyball, including the basic skills necessary for a rally.

In order to play volleyball, you need to know the basic moves.

These moves include:

  • Serving
  • Passing
  • Setting
  • Hitting
  • Defending
  • Blocking
